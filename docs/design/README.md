# Funmary の設計書

Funmary の設計の考え方と、その理由をまとめた文書です。開発に加わる人と、セルフホストを考える人に向けています。TypeScript と Web 開発の基本を知っていれば読めます。

> [!NOTE]
> この設計書は、実装に合わせて少しずつ足しています。まだ作っていない機能は、その章の中で「予定」と書いています。
