# 1. 概要と機能

## 1.1 Funmary は授業の予定を普段のカレンダーに届けるアプリ

Funmary (ファンマリー。FUN + summary) は、公立はこだて未来大学の学生向けの便利な総合 Web アプリです。大学とは関係のない、非公式のアプリです。主な使い方は次の 3 段階です。

1. 大学の Google アカウントでログインし、履修科目を登録する
2. 発行された URL を Google カレンダーや iPhone のカレンダーに登録する。以後、休講や教室変更を反映した授業の予定が自動で入る
3. 休講などが出たら、Discord や RSS リーダーで知らせを受ける。アプリ内の通知欄でも確かめられる

予定はカレンダーアプリに届くので、Funmary の画面を毎日開く必要はありません。画面を開くのは、授業の教室やシラバスを確かめるときと、設定を変えるときくらいです。

新しく登録できるのは、招待コードを持つ人だけです。

## 1.2 重視する 5 点

設計では次の 5 点を重視します。どう守るかは [3. 品質](03-quality.md) にまとめました。

- **速い**: 画面がすぐに出て、操作にすぐ反応する
- **軽い**: 端末に送る JavaScript を少なくし、古いスマホでも重くならない
- **使いやすい**: 必要な情報に 1 タップか 2 タップで着き、迷わない
- **サーバー負荷が小さい**: VPS 1 台、Node.js のプロセス 1 つ、SQLite のファイル 1 つで動く
- **壊れにくい**: 外部のサービスが止まっても、Funmary の画面と通知は動き続ける

年度替わりにコードを直さずに済むことも、方針に含めています。学期や祝日の期間は、学年暦から取り込むか、取れないときは手入力と推定に切り替えます。

## 1.3 機能

### 作った機能

| 機能                         | 内容                                                                                                                                                     |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 休講、補講、教室変更の取得   | 学生ポータルの一覧を、定期処理が 1 日 3 回取得する                                                                                                       |
| 個人の時間割                 | 履修科目、学期、祝日、振替授業日から授業の予定を作り、休講などを反映する                                                                                 |
| バス                         | 函館バスの時刻表を、画面、API、MCP、Discord の /bus で見る。BUS_API_BASE_URL を書いたときだけ有効 ([16 章](16-bus-timetable.md))                         |
| 授業の詳細                   | 科目ごとに、曜日と時限、教室、教員、単位数、公開シラバスの内容、休講などの履歴を表示する                                                                 |
| カレンダー購読               | 授業と学年暦の行事を ICS 形式で配信する                                                                                                                  |
| ログインと招待コード         | `@fun.ac.jp` の Google アカウントでログインする。新規登録には招待コードが要る                                                                            |
| 通知欄と Discord 通知        | 休講などをアプリ内の通知欄に記録し、Discord にも送る                                                                                                     |
| 通知のフィード               | 通知欄の中身を RSS、Atom、JSON Feed で配信する                                                                                                           |
| 公開 API と MCP              | 自分の時間割と休講を、AI エージェントや自作のスクリプトから読む ([2.3](02-architecture.md#23-ai-エージェントと外部のプログラム向けの口-公開-api-と-mcp)) |
| 汎用の Webhook               | 通知を、利用者が用意した URL にも送る                                                                                                                    |
| Discord のスラッシュコマンド | `/today`、`/next`、`/week`、`/changes` で、呼んだ人の授業と休講を答える。`/bus` で次のバスを答える                                                       |
| 予定のまとめ                 | 今日か明日の授業と予定を、設定した時刻に Discord へ 1 通にまとめて送る ([13.4](13-notifications.md#134-予定のまとめ))                                    |
| npm で配るパッケージ         | 公開 API のクライアント、手元の MCP、利用者向けのコマンドを npm で配る ([2.4](02-architecture.md#24-npm-で配るパッケージ))                               |

### 予定の機能

- ブラウザのプッシュ通知、授業前のリマインダー
- 欠席の記録
- QR コードでの時間割の共有、時間割の画像の書き出し
- Google カレンダーへの直接書き込み

### 作らない機能

学内マップ、学食メニュー、過去問、科目レビュー、お知らせ配信は作りません。教室は名前で表示するだけで、地図や空き状況は出しません。
