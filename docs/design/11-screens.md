# 11. 画面

## 11.1 ページの一覧

アプリの画面は、`/app` と `/app/*` の下に置きます。`/` は、ログインしているかどうかにかかわらず、紹介の画面で、ログイン済みなら「アプリを開く」を出します。ログインのあとは `/app` に移ります。`/app` に移す前の URL (`/week` や `/courses` など) は、`/app` の下へ 308 で転送します。

| パス                                                                                           | 内容                                                                                                       |
| ---------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------- |
| `/`                                                                                            | 紹介の画面。招待制のときは、招待コードの入力欄 (`/?code=` のリンクで、あらかじめ入れておける)              |
| `/app`                                                                                         | 今日の授業と予定、次の授業と教室、今日の休講、休講情報の最終取得時刻                                       |
| `/app/week`                                                                                    | 週の時間割。授業を押すと詳細を開く                                                                         |
| `/app/subjects/[年度]/[授業コード]`                                                            | 授業の詳細 ([11.2](#112-授業の詳細画面))                                                                   |
| `/app/courses`、`/app/courses/import`                                                          | 履修科目の登録。ポータルの時間割の取り込み                                                                 |
| `/app/events/*`                                                                                | 自分の予定の登録、直し、ほかの人の予定の閲覧と、時間割への追加                                             |
| `/app/notifications`                                                                           | 通知欄                                                                                                     |
| `/app/settings`                                                                                | 設定の入口                                                                                                 |
| `/app/settings/calendar`、`feed`、`webhooks`、`discord`、`tokens`、`invites`、`account`        | カレンダーの購読、お知らせのフィード、Webhook、Discord 連携、公開 API と MCP、招待、データの書き出しと退会 |
| `/app/admin/*`                                                                                 | 管理画面 ([11.5](#115-管理画面))。管理者と、一部はモデレーターだけ                                         |
| `/oauth/authorize`                                                                             | MCP のコネクタが開く、アクセスの許可の画面                                                                 |
| `/consent`                                                                                     | 利用規約への同意の画面                                                                                     |
| `/login`、`/terms`、`/privacy`、`/about`、`/license`、`/contributors`、`/third-party-licenses` | ログインと、規約、このアプリについての画面。ログインしていなくても開ける                                   |

作っていない画面は、載せていません。欠席の記録と、時間割の共有リンクは予定です。

## 11.2 授業の詳細画面

時間割から授業を押すと開きます。1 画面で、次のことが分かります。

- 科目名、教員、単位数、学期、対象学年
- 曜日と時限、教室。教室変更があれば、変更後の教室を示す
- シラバスの内容 (授業の概要、到達目標、授業計画、成績評価の方法、教科書)。長い項目は折りたたむ
- シラバスの原文へのリンク
- この科目の休講、補講、教室変更の履歴

シラバスの内容は、取り込むときに `subjects` へ保存しておくので、画面を開くたびに大学のサイトへは取りに行きません。

## 11.3 色は、大学のロゴの赤を基調にする

大学の公式サイトのロゴと CSS から色を拾い、SMUI (Material Design の Svelte 版) のテーマに入れています。ロゴの文字の色と、サイトの CSS で最も多く使われている色は、どちらも `#9d2126` (深い赤) でした。

| 役割                             | ライト    | ダーク    |
| -------------------------------- | --------- | --------- |
| primary (上部のバー、主なボタン) | `#9d2126` | `#d6999e` |
| secondary (リンク、補助のボタン) | `#3d6cbc` | `#9fb8e6` |
| 本文の文字                       | `#333333` | `#e6e1e1` |
| 背景                             | `#ffffff` | `#141212` |

文字と背景のコントラストは、WCAG AA (本文で 4.5:1 以上) を満たすようにします。

**状態は、色だけで伝えない。** 休講を示す色と、アプリの主色が、どちらも赤になるので、状態には必ず文字 (「休講」「補講」「教室変更」) を添えます。休講には取り消し線も付けます。

**大学のロゴや校章は、使わない。** Funmary は、大学とは無関係の非公式のアプリです。公式のものと誤解されないよう、参考にするのは色だけにして、アプリのアイコンは別に作っています。画面の下部と README に、非公式であることを書いています。

## 11.4 スマホと PC の両方で使える

どの端末でも、ブラウザで開く Web アプリです。スマホを基準に作り、同じ画面を、PC でも使いやすい配置に変えます。端末ごとに別の画面は作らず、1 つのコンポーネントを画面幅で組み替えます。

画面幅の区切りは、Material Design の画面幅の区分に合わせて、840px の 1 か所だけです。スタイルでは `_breakpoints.scss` の mixin で書き、数字をほかの場所に書きません。

| 画面幅     | 想定する端末               | 移動のメニュー         | 配置                                       |
| ---------- | -------------------------- | ---------------------- | ------------------------------------------ |
| 840px 未満 | スマホ、縦向きのタブレット | 画面下部のタブ         | 1 列                                       |
| 840px 以上 | PC、横向きのタブレット     | 左側に常に出すメニュー | 本文の幅には上限を置き、横に間延びさせない |

ページ本文の幅は、`base.scss` の `.page` (既定は 44rem) と、`.page-w-<rem>` の修飾で決めます。広い表がある画面だけ、広げています。

PC の操作にも合わせます。

- キーボードだけで、すべての操作ができる。フォーカスの位置が見え、Tab の順番は画面の見た目の順番に合わせる
- マウスを載せたときの見た目 (hover) を付ける。ただし、スマホには hover がないので、hover でしか出ない情報は作らない
- 押せる範囲の大きさは、表示や状態が変わっても保つ。ボタンや欄が動いて、押し間違えないようにする

E2E のテストには、スマホの幅 (390px) で、主な画面が横にはみ出さないことを確かめるものがあります。

画面は、ライトとダークの両方で確かめます。端末の設定に従う「自動」のほか、画面の上のボタンで、ライトとダークを選べます。

## 11.5 管理画面

`/app/admin/*` は、管理者に、一部の画面はモデレーターにも開きます。権限のない人には、画面があることを見せないよう、404 を返します。

| 画面                         | 内容                                                                 |
| ---------------------------- | -------------------------------------------------------------------- |
| 授業名の照合                 | 科目と照合できなかった授業名を、手で紐付ける                         |
| 曜日と時限の確認             | 利用者が提出した曜日と時限を確認する (モデレーターも)                |
| 学年暦                       | 学期の期間、振替授業日、全学の休講日の確認と入力                     |
| 時間割の取り込み             | 大学が配る PDF から、曜日、時限、教室を入れる                        |
| 招待コード、サポートサーバー | 招待コードを発行できる人と、発行されたコード。サポートサーバーの招待 |
| テストアカウント             | 大学のアカウントでない Google のアカウントで、機能を試す             |
| 取得元と実行履歴             | 取得元の状態、定期処理の実行記録、配信の失敗、応答時間               |
| Webhook、Discord             | 1 人あたりの Webhook の上限、Discord の Bot の配置                   |
| 監査ログ                     | 管理の操作の記録 (モデレーターも)                                    |
