# 9. 年度替わりに手を入れずに済む設計

年度や学期で変わる値をコードに書くと、毎年、更新とデプロイが要ります。Funmary は、そうした値を実行時に取得するか、計算で求めます。取得できない値だけは、管理画面から入力できるようにして、デプロイは要らないようにします。

| 年度で変わるもの                     | 決め方                                                                                                                                                                       |
| ------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| ポータルのログインで送る年度と学期   | ログインの画面の選択肢で、既定になっている値を使う。読めなければ、日付から計算する                                                                                           |
| 休講一覧の日付の年                   | 実行日と年度から補う                                                                                                                                                         |
| 科目と時間割                         | 日付から年度を決め、その年度のシラバスを取り込む。新年度のシラバスが公開されていなければ、前年度のものを使い続けて、毎日確かめる。科目は、年度とシラバスの番号の組で区別する |
| 履修科目                             | 学期が切り替わる前に、次の学期の科目を登録するよう、通知で促す。通年の科目は引き継ぐ                                                                                         |
| 祝日                                 | 内閣府の CSV を週に 1 回取り込む ([8.6](08-data-fetching.md#86-祝日))                                                                                                        |
| 学期の期間、振替授業日、全学の休講日 | 下の 3 段階で決める                                                                                                                                                          |
| 時限の時刻                           | コードの初期値 (`DEFAULT_PERIODS`) を使う。管理画面で変えられるようにするのは、予定                                                                                          |

## 9.1 学期の期間と振替授業日

次の順に、値を探します。

1. **管理画面で入力された値**。自動で取得できないときや、取得した値が誤っているときに使います。自動で取った値より先に使うので、管理者が直せます
2. **大学サイトの学年暦から、自動で取得した値**。大学サイトの「教育に関する情報」から「(年) 学年暦」の PDF を探し、月に 1 回読み取ります。PDF のセルの塗りの色で、授業日を判定します (濃い灰色は 1Q と 3Q、薄い灰色は 2Q と 4Q、緑は集中講義、塗りなしは授業なし)。どの色がどれかは、凡例から読みます。全セルの日付の数字を暦と照らし合わせ、1 つでも合わなければ、読み取りをやめます。取得か読み取りに失敗したら、管理者に知らせます。管理者が PDF を渡して取り込むこともできます (管理用コマンド `funmary-admin calendar import <PDF>`。`--apply` を付けるまでは確かめるだけです)
3. **既定の規則で推定した値**。前期は 4 月 1 日から 7 月末、後期は 9 月の第 3 月曜から翌年 1 月末、のような、大学の授業期間より広めの仮の規則を置きます。推定の値を使っている間は、管理画面と、管理者への通知で入力を促します。画面と API でも、推定を使っていることが分かります (`usesEstimatedTerms`)

学年暦の行事名からは、振替授業日 (「月曜振替授業」なら、その日は月曜の授業を行う) と、全学の休講日を読み取ります。祝日に授業を行う日が学年暦にあれば、それも拾います。

振替授業日は、推定できません。取得も入力もされていなければ、ふつうの曜日として扱い、その旨を管理者へ知らせます。

これで、年度替わりのコードの変更とデプロイは要りません。学年暦が自動で取れなかった場合でも、管理者の作業は、年に 1 回、管理画面で日付を数か所入れるだけです。

## 9.2 テストでも年を固定しない

現在の時刻は、引数で渡します。テストでは、複数の年度の日付を与えて確かめます。
