# プロダクトの方針

画面を作る人と、AI エージェントに向けた、Funmary が何のためにあるかの要約です。詳しい設計は [設計書](design/README.md) にあります。

## 誰のための何か

公立はこだて未来大学の学生が、授業の予定、休講、教室の変更を、いつもの道具 (カレンダー、Discord、RSS リーダー) で、見逃さずに受け取るための、非公式の Web アプリです。大学とは関係がありません。

- 主な使い方は、大学の Google アカウントでログインし、履修科目を登録して、カレンダーの購読 URL を発行すること。画面を毎日開かなくても、予定と知らせが届く
- 画面を開くのは、教室やシラバスを確かめるとき、設定を変えるとき
- 開発者、AI エージェント向けに、公開 API と MCP でも、同じ情報を読める (読み取り専用)

## 守る価値

- **見逃さない**: 休講と教室の変更を、早く、正確に知らせる。誤った通知は、遅れた通知より悪い (取り消しは 2 回続けて消えたときだけ、など)
- **速く、軽く、使いやすい**: 必要な情報に 1 タップか 2 タップで着く。古いスマホでも重くならない
- **壊れにくい**: 大学のサイトが止まっても、ある情報で動き続け、古いときは「古い」と示す
- **預かるものを減らす**: ポータルのパスワードなど、大学のアカウントの秘密は預からない。個人の情報は、最小限にする
- **非公式であることを隠さない**: 大学のロゴは使わない。非公式と明記する

## 語り口

- 日本語で、短く、具体的に。「〜してください」より、状態と次にできることを書く
- 不具合や制限は、隠さず、理由と、できることを添える
- 状態は、色だけで伝えず、必ず文字を添える

## 作らないもの

大学が出す公式の情報の代わり、成績や出席の管理、広告、学生の行動の追跡。学生ポータルの代わりにはならず、ポータルへの接続は、定期処理だけが、最短 60 分の間隔で行う。
