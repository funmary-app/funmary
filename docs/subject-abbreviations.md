# 科目の略称

デフォルトの略称は `apps/web/src/lib/server/subject-abbreviations.json` で編集します。科目名を左側、略称を右側にしたJSONで、科目名は変更せず、右側の値を編集してください。略せない科目は空欄にすると正式名称を表示します。

2026年度の[公開シラバス](https://students.fun.ac.jp/lesson/SyllabusList)の授業一覧341件から、同名の科目をまとめた338件を記載しています。学年やクラスなどが付いた科目名も、一覧の表記をそのまま使っています。同じ正式名称の科目には、年度を問わず同じデフォルト略称を使います。

```json
{
  "架空の長い授業名": "架空授業",
  "架空の別の授業": ""
}
```

変更後にビルドして反映してください。このファイルにない科目や、空欄の科目には正式名称を表示します。利用者が追加した科目も、個人用の略称を設定できます。

## 略称の初期値

338件中336件には、"コミュニケーション" を "コミュ" に置き換え、学年とクラスの表記を除いた略称を入力しています。`1～4`、`M1,2`、`M1`、`M2`、学年を示す単独の数字、`-ABCD` などのクラス表記を除きました。`- JKL` や `-GHIの半分` もクラス表記として除いています。

ローマ数字、科目を区別する `(1)`・`(2)`、9月入学の注記、集中講義や高度ICTの表記は残しています。指定パターンに当てはまらない "システム情報科学特別研究D" と "特別ゼミナールD" は空欄です。新しく追加する科目の略称は手動で入力してください。

## 科目一覧の更新

シラバスを取り込んだDBがある場合は、リポジトリのルートで次を実行すると、科目名を追加できます。DBは読み取り専用で開き、入力済みの略称は残します。利用者が追加した科目は、非公開の科目名が公開ファイルに入ることを避けるため、含めません。

```powershell
node scripts/export-subject-abbreviations.js "C:\path\to\funmary.db"
```

## 個人用の略称

科目画面の "略称を編集する" で保存すると、その利用者と科目の組にだけ値を保存します。保存していない科目はデフォルトを使い、空欄を保存した科目はデフォルトがあっても正式名称を使います。共有の科目名は変更しません。

時間割の "略称表示" は初期状態ではオフです。オンにするとセル内の科目名だけが切り替わり、科目画面、ホーム画面、通知、フィードなどには正式名称を使います。オンとオフはブラウザに記憶します。

## トグル部品

`ToggleButton.svelte` は、表示ラベル、オン・オフの値、無効状態、切り替え時の処理を受け取る共通部品です。外枠の見た目は `toolbar-button.scss` で既存の時間割ボタンと共有しています。

内部のスイッチは[Material Webのスイッチ](https://material-web.dev/components/switch/)を参考に、トラックを52px × 32px、つまみをオフ時16px、オン時24pxにしています。色やトラックの大きさは部品内の `--fm-switch-*` のCSS変数で変更できます。ボタン全体を押せるようにし、キーボード操作、読み上げ用のオン・オフ状態、動きを減らす設定に対応しています。
