# 用語集

Funmary で使う用語と、コードで使う英語の名前の対応です。画面や文書では日本語の用語を、コードでは右の列の名前を使います。新しい用語が出てきたら、ここに足します。

## 利用規約への同意

| 用語       | コードでの名前       | 意味                                                                                       |
| ---------- | -------------------- | ------------------------------------------------------------------------------------------ |
| 規約の版   | `termsVersion`       | 同意を求める利用規約とプライバシーポリシーの版。2 つの最終更新日のうち、新しいほうの日付   |
| 再同意     | `consent`            | 登録のあと、または規約の更新のあとに、同意の画面で同意すること。同意するまで全機能を止める |
| 同意の待ち | `termsGate` (API 側) | 利用者が、いまの版に同意していない間、公開 API、MCP、購読が機能を止めること                |

## 授業と時間割

| 用語         | コードでの名前    | 意味                                                                                               |
| ------------ | ----------------- | -------------------------------------------------------------------------------------------------- |
| 科目         | `subject`         | シラバスに載っている授業の単位。年度とシラバスの番号の組で区別する                                 |
| 略称         | `abbreviation`    | 時間割のセルだけに使う科目名の短い表記。個人の保存値をデフォルトより優先し、空欄なら正式名称を使う |
| コマ         | `slot`            | 科目が行われる曜日と時限の組。1 つの科目が複数のコマを持つことがある                               |
| 時限         | `period`          | 1 日の中の授業の枠。1 限から 6 限まである                                                          |
| 履修科目     | `registration`    | 利用者が登録した、自分が受けている科目                                                             |
| 授業         | `lesson`          | ある日のある時限に実際に行われる 1 回分の授業。時間割の展開で作る                                  |
| 時間割の展開 | `expandTimetable` | 履修科目、学期、祝日などから、日付ごとの授業を作る処理                                             |

## 休講など

| 用語       | コードでの名前 | 意味                                                                               |
| ---------- | -------------- | ---------------------------------------------------------------------------------- |
| 休講       | `cancellation` | 授業が行われなくなること                                                           |
| 補講       | `makeup`       | 休講などを補うために追加で行う授業                                                 |
| 教室変更   | `roomChange`   | 授業の教室がその回だけ変わること                                                   |
| 休講など   | `classChange`  | 休講、補講、教室変更をまとめた呼び方                                               |
| 補講の予定 | `makeupPlan`   | 休講コメントの冒頭にある "補講あり"、"補講なし"、"補講未定"                        |
| 授業名     | `lessonName`   | 休講一覧などに書かれた授業の名前。科目との照合の前の、ポータルの表記のままの文字列 |

## 暦

| 用語       | コードでの名前     | 意味                                                                     |
| ---------- | ------------------ | ------------------------------------------------------------------------ |
| 年度       | `academicYear`     | 4 月に始まり、翌年の 3 月に終わる 1 年。2026 年度は 2026-04 から 2027-03 |
| 学期       | `term`             | 前期、後期、1Q から 4Q、夏期集中、冬期集中、通年                         |
| 学年暦     | `academicCalendar` | 大学が公開する、学期の期間や行事の予定                                   |
| 振替授業日 | `substituteDay`    | 別の曜日の授業を行う日。例: 水曜に月曜の授業を行う                       |
| 祝日       | `holiday`          | 内閣府の祝日 CSV に載っている祝日と休日                                  |

## 取得と通知

| 用語                 | コードでの名前 | 意味                                                                                                                                                           |
| -------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 取得元               | `source`       | Funmary が情報を取りに行く外部のサービス (学生ポータル、シラバス、HOPE、学年暦、祝日)                                                                          |
| 取得元の見張り       | `sourceHealth` | 取得元ごとに失敗の回数を数え、続けて失敗したら試す間隔を広げる仕組み                                                                                           |
| 通知欄               | `inbox`        | 利用者ごとの、アプリ内の通知の一覧。利用者への通知の正本                                                                                                       |
| 通知                 | `notification` | 通知欄に入る、利用者への 1 件の知らせ                                                                                                                          |
| チャネル             | `channel`      | 利用者が登録した通知の送り先 (Discord の Webhook、プッシュ通知、メール)                                                                                        |
| 管理用の通知         | `adminAlert`   | Funmary 自体の状態 (取得元の不調、エラー、反映の結果) を運用する人に知らせるもの。通知欄やチャネルとは別で、環境変数に書いた管理用の Discord の Webhook に送る |
| 配信                 | `delivery`     | 1 件の通知を 1 つのチャネルへ送ること。再送の管理に使う                                                                                                        |
| Discord 連携の送り先 | `discordLink`  | Discord 連携で選んだ、非公開スレッドか DM。通知を送るチャネルとして、連携のたびに作り、解除したら消す                                                          |
| 予定のまとめ         | `dailyDigest`  | 今日か明日の授業 (休講などを含む) と予定を、利用者が選んだ時刻に、Discord 連携の送り先へ 1 日 1 通で送るもの。通知欄には入らない                               |
| フィード             | `feed`         | 通知欄の中身を RSS、Atom、JSON Feed で配るもの                                                                                                                 |
| 購読の URL           | `calendarFeed` | カレンダーアプリに登録する、利用者ごとの ICS の URL (`/cal/<トークン>.ics`)。トークンはハッシュだけを保存し、URL は発行の直後に 1 回だけ見せる                 |

## アカウント

| 用語       | コードでの名前 | 意味                                         |
| ---------- | -------------- | -------------------------------------------- |
| 利用者     | `user`         | Funmary にログインする人                     |
| 管理者     | `admin`        | 招待コードの発行や取得元の管理ができる利用者 |
| 招待コード | `inviteCode`   | 新規登録に必要なコード                       |
