# 用語集

Funmary の画面や文書に出てくる用語と、対応するコード上の名前をまとめます。新しい用語を使うときは、この一覧に追加します。

## 利用規約への同意

| 用語               | コードでの名前       | 意味                                                                                                           |
| ------------------ | -------------------- | -------------------------------------------------------------------------------------------------------------- |
| 規約のバージョン   | `termsVersion`       | 利用規約とプライバシーポリシーの最終更新日のうち、新しいほうの日付。どの内容への同意かを区別する               |
| 規約への同意       | `consent`            | 登録後に利用規約とプライバシーポリシーを確認して同意すること。文書の更新後にもう一度同意することを再同意と呼ぶ |
| 規約への同意が必要 | `termsGate` (API 側) | 利用者が現在のバージョンに同意していない状態。公開 API、MCP、購読などで利用が制限される                        |

## 授業と時間割

| 用語         | コードでの名前    | 意味                                                                                                                 |
| ------------ | ----------------- | -------------------------------------------------------------------------------------------------------------------- |
| 科目         | `subject`         | 時間割や履修登録で扱う授業の単位。公開シラバスから取り込んだ科目と、利用者が追加した科目がある                       |
| 略称         | `abbreviation`    | 時間割のセルに表示する短い科目名。利用者が設定した略称をデフォルトより優先し、空欄を保存したときは正式名称を表示する |
| コマ         | `slot`            | 科目が行われる曜日と時限の組。1 つの科目が複数のコマを持つことがある                                                 |
| 時限         | `period`          | 1 日の中の授業の枠。1 限から 6 限まである                                                                            |
| 履修科目     | `registration`    | 利用者が自分の時間割に登録した科目                                                                                   |
| 授業         | `lesson`          | 時間割に載る、特定の日付の 1 回分の授業。休講や教室変更もこの単位で扱う                                              |
| 時間割の展開 | `expandTimetable` | 履修科目、学期、祝日などから、日付ごとの授業を作る処理                                                               |
| 時間割の画像 | `timetableImage`  | 週の時間割を PNG や PDF に書き出した画像                                                                             |

## 休講など

| 用語       | コードでの名前 | 意味                                                                               |
| ---------- | -------------- | ---------------------------------------------------------------------------------- |
| 休講       | `cancellation` | 授業が行われなくなること                                                           |
| 補講       | `makeup`       | 休講などを補うために追加で行う授業                                                 |
| 教室変更   | `roomChange`   | 授業の教室がその回だけ変わること                                                   |
| 休講など   | `classChange`  | 休講、補講、教室変更をまとめた呼び方                                               |
| 補講の予定 | `makeupPlan`   | 休講理由の冒頭にある「補講あり」「補講なし」「補講未定」の区分                     |
| 授業名     | `lessonName`   | 休講一覧などに書かれた授業の名前。科目との照合の前の、ポータルの表記のままの文字列 |

## 暦

| 用語       | コードでの名前     | 意味                                                                     |
| ---------- | ------------------ | ------------------------------------------------------------------------ |
| 年度       | `academicYear`     | 4 月に始まり、翌年の 3 月に終わる 1 年。2026 年度は 2026-04 から 2027-03 |
| 学期       | `term`             | 前期、後期、1Q から 4Q、夏期集中、冬期集中、通年                         |
| 学年暦     | `academicCalendar` | 大学が公開する、学期の期間や行事の予定                                   |
| 振替授業日 | `substituteDay`    | 別の曜日の授業を行う日。例: 水曜に月曜の授業を行う                       |
| 祝日       | `holiday`          | 内閣府の祝日 CSV に載っている祝日と休日                                  |

## 取得と通知

| 用語                 | コードでの名前 | 意味                                                                                                                             |
| -------------------- | -------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| 取得元               | `source`       | Funmary が情報を取りに行く外部のサービス (学生ポータル、シラバス、学年暦、祝日など)                                              |
| ダイヤの版           | `generation`   | バスの時刻表が、事業者のダイヤ改正ごとに変わる単位。有効になる日の 8 桁 (20261001) で区別する                                    |
| 取得元の状態         | `sourceHealth` | 最後に取得を試した日時、成功した日時、連続失敗回数、次に試せる日時など。失敗が続くと試行間隔を延ばす                             |
| 通知欄               | `inbox`        | 利用者ごとのアプリ内通知一覧。Discord や通知フィードに配信する通知の元になる                                                     |
| 通知                 | `notification` | 通知欄に入る、利用者への 1 件の知らせ                                                                                            |
| チャネル             | `channel`      | DB に保存する通知先とその設定。Discord 連携、Discord の Webhook、汎用 Webhook などがある                                         |
| 管理用の通知         | `adminAlert`   | 取得元の不調や更新の結果などを、設定された Discord の通知先へ運用者向けに送る通知                                                |
| 配信                 | `delivery`     | 1 件の通知を 1 つの通知先へ送る処理。送信結果や再送を通知先ごとに管理する                                                        |
| Discord 連携の送り先 | `discordLink`  | Discord 連携で選んだ、非公開スレッドか DM。通知を送るチャネルとして、連携のたびに作り、解除したら消す                            |
| 学期の始まり         | `termStart`    | 前期か後期が始まったときに、その学期の科目を 1 つも履修していない利用者へ、履修登録を促す通知の種類                              |
| 予定のまとめ         | `dailyDigest`  | 今日か明日の授業 (休講などを含む) と予定を、利用者が選んだ時刻に、Discord 連携の送り先へ 1 日 1 通で送るもの。通知欄には入らない |
| フィード             | `feed`         | 通知欄の中身を RSS、Atom、JSON Feed で配るもの                                                                                   |
| カレンダーの購読 URL | `calendarFeed` | カレンダーアプリが、授業や予定を ICS で取得するための URL                                                                        |
| 通知の購読 URL       | `feedTokens`   | フィードリーダーが、通知を RSS、Atom、JSON Feed のいずれかで取得するための URL                                                   |

## 公開 API と MCP

| 用語       | コードでの名前   | 意味                                                                             |
| ---------- | ---------------- | -------------------------------------------------------------------------------- |
| MCP ツール | `ToolDefinition` | AI エージェントが MCP サーバーで呼び出す操作。今日の授業の取得や、予定の追加など |

## アカウント

| 用語       | コードでの名前 | 意味                                         |
| ---------- | -------------- | -------------------------------------------- |
| 利用者     | `user`         | Funmary にログインする人                     |
| 管理者     | `admin`        | 招待コードの発行や取得元の管理ができる利用者 |
| 招待コード | `inviteCode`   | 新規登録に必要なコード                       |
